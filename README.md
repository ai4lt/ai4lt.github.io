# AI4LT Demo Showcase

A bilingual, event-focused landing page for AI4LT demos, intended for publication at <https://ai4lt.github.io>.

## Edit demos

All demo URLs, tags, and English/German descriptions are in `demos.js`. An empty `url` displays “Link coming soon” instead of a clickable launch action.

## Preview locally

Run `python3 -m http.server 8000` and open <http://localhost:8000>.

## Publish

Create the repository `ai4lt/ai4lt.github.io`, push these files to its default branch, then choose **Deploy from a branch** and `/(root)` under **Settings → Pages**. GitHub will publish the site at <https://ai4lt.github.io>.

## Before launch

- Confirm the descriptions and links for every demo.
- Confirm that KIT's legal notice and privacy policy cover this separately hosted site.
- Replace or supplement the abstract demo graphics with approved screenshots if desired.
- Test all login-protected demos in the intended event environment.
